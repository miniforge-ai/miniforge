The Worry Book

The Thesium Codex, explained simply. Same yard as the fort-building robots: same coach, same no-ears checkers, same red stickers. Grown-up translation table at the end.

A book of bruises

In the garage, next to the board, there is a book. It is not a rulebook. Every page is a worry: a thing that went wrong before and could go wrong again. And every worry has a bruise photo taped to it: what happened, when, and how much it hurt. Some bruises are ours. Some we borrowed from the neighbors, who were kind enough to show us theirs.

A worry without a bruise photo gets a little flag on it, so nobody mistakes a guess for a lesson. And worries come in three sizes: whole-fort worries, this-week worries and this-board worries. The book always tells you the whole-fort ones first.

Finding the right page

Nobody reads the whole book. The front pages ask where are you standing? About to do something you can't undo. About to change one side of something two pieces share. The wiggle test said fine, but…

The book then hands you, all at once, every worry page you could reach from there, and the questions that split them up. Each question has only a few allowed answers. Is it moving at all? Slow but moving, or not moving? Answering doesn't turn any pages: you already have them all.

If nothing matches where you're standing, the book says so out loud. A blank page never means "safe." And if no whole-fort worry turns up, it says that too.

Pinned to the bench

Here's the coach's new job. Before the job-list robot or a builder robot starts, the coach looks up the page for where that robot is standing and pins it to the robot's bench. A builder changing one side of a shared piece also gets the page about wiggle tests, because the checkers will judge its work.

The checker who looks over the finished fort has no bench, so the coach reads the page aloud instead. The same goes for the robot who carries the fort out to the street. And any robot, any time, can walk over and open the book itself.

Did you look?

Every time a robot opens a page, the no-ears checker writes it down. If the robot asked for the pinned page and found the bench empty, that counts as not looking.

If you told the coach to use the book and the book never opened, that's a red sticker. Building without the book you asked for is building blind. If the page was pinned right there but the robot never picked it up, that's only a yellow note. The whole page stays pinned even when the bench gets crowded and everything else is swapped for its name, so the robot saw it anyway. Only a page too big for the whole bench gets just its name pinned. The yellow notes go in the proof notebook with everything else, so they're still there after a do-over.

Robots also write down how they answered each question. That shows which questions still help.

The miss notebook

Sometimes something goes wrong anyway. Then a robot writes it in the miss notebook and asks, in order:

1. Was there even a page for where we were standing?

2. Did the right worry come up from that page?

3. Did the page actually reach the robot?

4. With the page right there, did the robot steer clear?

The first "no" gets the blame, never a later one. If the notebook can't tell which worry it was, the miss goes in a not sure yet pile. Nobody gets blamed for it, but it stays on the to-learn list.

Later, someone reads the old misses again against the newest book: would today's pages have caught that? And someone checks which questions everybody always answers the same way, because a question like that has stopped helping.

Who writes the pages

This part happens in the library, not the garage, and our drawing of it is still a sketch.

The librarian reads through old sticky notes and turns them into questions, not answers. The librarian also collects bruise photos from neighbors. A new page gets into the book only if it changes where you'd end up; a page that sounds wise but sends everyone to the same place gets politely refused. A page that would have caught real misses gets promoted. A question nobody needs anymore gets retired.

The garage robots never write in the book. They only read it.
